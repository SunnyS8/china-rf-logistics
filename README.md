# China RF Logistics

Калькулятор логистических ставок: сравнение маршрутов доставки контейнеров 40'HC
из Китая (Шанхай, Нинбо, Циндао) на склады в РФ (Серпухов, Ставрополь).

## Возможности

- **Автопарсинг ставок из Excel** — выбери папку с файлами перевозчиков (ИГЛ,
  Галеос, Дельпорте, порт Циндао) — парсер сам извлечёт фрахт, Ж/Д, авто, вознаграждение
- **Расчёт полной стоимости** — фрахт ($) + Ж/Д (₽) + автовывоз (₽) + терминальные,
  всё пересчитывается в USD по курсу на дату согласования
- **Сравнение и сортировка** — самые дешёвые (BEST PRICE) и самые быстрые (FASTEST)
- **История изменений ставок** — автосохранение версий, восстановление, сравнение цен
- **Валидация данных** — подсветка ошибок и подозрительных значений
- **Фильтры** — по складу, типу маршрута (Море + Ж/Д, Прямое Ж/Д, Deep Sea), поиск
- **Итоговый отчёт** — копирование сводки и печать в PDF

## Запуск

```bash
npm install
npm run dev
```
